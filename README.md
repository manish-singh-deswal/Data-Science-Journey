# My Data Science Journey — Week 1 to 36

> **36 weeks of structured learning, coding, practice, and continuous improvement — from Python fundamentals to machine learning.**

This repository documents my 36-week journey of building a strong data science foundation.

It is more than a collection of course notes. It is a record of consistent weekly effort: learning concepts, implementing them in code, revising them, and gradually connecting programming, data analysis, statistics, mathematics, SQL, and machine learning.

## Why I Built This Repository

I wanted to learn data science systematically rather than study isolated tools and algorithms.

My approach was:

**Learn → Understand → Implement → Practice → Revise → Move Forward**

The goal was not only to complete a course, but to build the technical foundation needed to work on real-world data science problems—especially in financial analytics and credit risk.

## Learning Roadmap

| Phase | Weeks | Topics |
|---|---:|---|
| **Python Foundations** | 1–4 | Python basics, data types, OOP, advanced Python |
| **Data Handling** | 5–8 | NumPy, Pandas, advanced Pandas |
| **Visualization & Analysis** | 9–12 | Data visualization, exploratory data analysis, data-analysis workflow |
| **SQL** | 13–16 | SQL fundamentals, advanced SQL, querying, and data extraction |
| **Statistics & Mathematics** | 17–22 | Descriptive statistics, probability, inferential statistics, hypothesis testing, and linear algebra |
| **Core Machine Learning** | 23–27 | Linear regression, gradient descent, regression analysis, feature selection, and regularization |
| **Machine Learning Algorithms** | 28–36 | KNN, PCA, model evaluation, Naive Bayes, logistic regression, SVM, ,decision trees ,Random forest, Gradient Boosting |

## What This Journey Taught Me

- **Consistency compounds.** Working every week turned individual topics into connected knowledge.
- **Implementation creates understanding.** Writing code made it necessary to understand how and why methods work, not only what they do.
- **Fundamentals matter.** Python, SQL, statistics, probability, and linear algebra make it possible to reason about machine-learning models instead of treating them as black boxes.
